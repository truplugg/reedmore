# READMORE

Украинский книжный магазин с доставкой по ЕС и Украине.
Статический сайт без сборки: открывается по любому HTTP-адресу, деплоится
куда угодно — GitHub Pages, Netlify, Vercel, S3, nginx.

---

## Быстрый старт

Модули подключены как ES-модули, поэтому нужен HTTP (через `file://`
браузер их заблокирует):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Любой статический сервер подойдёт: `npx serve`, `php -S`, nginx.

## Раскрывающаяся книга

Главный элемент. Обложка закреплена на корешке
(`transform-origin: left center`) и поворачивается на −154° вокруг оси Y.
За ней — форзац (обратная сторона обложки, со своим узором у каждой книги)
и первая страница с аннотацией и колофоном: формат, бумага, переплёт, ISBN.

**Управление**

| Устройство | Действие |
|---|---|
| Мышь | наведение раскрывает, клик открывает карточку |
| Палец | первое касание раскрывает, второе открывает карточку |
| Клавиатура | `Tab` раскрывает, `Enter` открывает карточку, `Esc` закрывает |

Открыта всегда одна книга: соседние приглушаются, чтобы развороту
хватило места. `placeSpread()` в `book3d.js` считает сдвиг так, чтобы
разворот не вылез за край контейнера — это работает и для крайних книг
в ряду, и для двух колонок на телефоне.

При `prefers-reduced-motion: reduce` 3D отключается: обложка просто
исчезает, открывая разворот.

## Данные каталога

`assets/js/data/books.js` — обычный ES-модуль. Заменяется на запрос
к вашему API без изменений в остальном коде: `catalog.js`, `cart.js` и
`palette.js` работают с массивом `BOOKS`.

Поля одной книги:

```js
{
  id, title, titleEn, author, authorEn, year, publisher,
  genre,            // proza | klasyka | poeziia | nonfic | dytiacha
  tags: [],
  format,           // hard | soft
  pages, size, paper, binding, isbn, weight,
  price,            // в гривнах — базовая валюта
  oldPrice,         // если есть скидка
  rating, reviews, stock,
  badge,            // new | best | preorder | last | null
  blurb, blurbEn,   // короткая аннотация — печатается на странице книги
  about, aboutEn,   // развёрнутая — в карточке
  cover: { style, pal, motif },
  endpaper
}
```

**Обложки генерируются, а не загружаются.** `covers.js` собирает их из
шести типографических шаблонов (`stack`, `band`, `plate`, `column`,
`serif`, `split`) и девяти геометрических плашек. Ни одна издательская
обложка не воспроизводится. Если появятся права на реальные изображения —
достаточно заменить `coverHTML()` на `<img>`.

## Валюты и языки

Валюты объявлены в `store.js` → `CURRENCIES`. Базовая — гривна; курсы
сейчас зашиты константами, перед запуском их нужно брать из фида
платёжного провайдера. Округление задаётся полем `step`.

Языки — в `i18n.js`. Новый язык добавляется одним блоком ключей в `DICT`
и строкой в `LANGS`; разметка уже размечена `data-i18n` и
`data-i18n-attr`, дополнительной работы не требуется.

## Доставка

`delivery.js` считает по зонам: базовая ставка плюс цена за килограмм,
вес считается как 380 г на книгу плюс 180 г на коробку. Перевозчик и срок
у каждой зоны свои. Бесплатная доставка — от порога `FREE_FROM_UAH`
в `store.js`. Перед запуском таблицу зон заменить на тарифы перевозчиков.

## Состояние

Корзина, список желаемого, язык, валюта, тема и вид каталога хранятся
в `localStorage` под ключом `readmore.v1`. Каждое обращение обёрнуто
в `try/catch`: в приватном окне и при заблокированных данных сайта
хранилище бросает исключение, и страница должна работать всё равно.

Фильтры каталога живут в адресной строке (`?q=&g=&f=&s=&w=`) — отфильтрованную
полку можно отправить ссылкой.

## Доступность

Семантическая разметка, видимый фокус, ссылка «к основному содержимому»,
`aria-expanded` на книгах, ловушка фокуса в модальном окне, управление
с клавиатуры во всех оверлеях, уважение к `prefers-reduced-motion`,
поддержка светлой и тёмной темы плюс системной настройки.

## Деплой

Обычная статика, шагов сборки нет.

**GitHub Pages:** Settings → Pages → Deploy from a branch → ветка и
корень `/`. Файл `.nojekyll` уже лежит в репозитории.

**Netlify / Vercel:** build command пустой, publish directory — корень.

## Демоданные

Названия книг, авторы и издательства — настоящие. Цены, наличие, ISBN,
рейтинги и отзывы — тестовые значения. Обложки — оригинальный
типографический дизайн, а не репродукции издательских. Об этом сказано
и в подвале сайта.
